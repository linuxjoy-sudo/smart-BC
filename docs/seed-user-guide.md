# SmartBC 种子用户使用指南

## 安装包路径

- Windows 安装包：`src-tauri/target/release/bundle/nsis/*.exe`（`npm run tauri build` 生成）
- 运行环境：Windows 10/11 桌面版

## 首次使用流程

1. **配置 API Key**：打开应用 →「设置」→ 输入 DeepSeek API Key → 保存。
   （也可设置环境变量 `DEEPSEEK_API_KEY`，优先于设置页）
2. **下载 Whisper 模型**：应用会自动使用 `{数据目录}/models/ggml-small.bin`。
   若模型不存在，可手动下载放置：
   - 下载地址：`https://hf-mirror.com/ggerganov/whisper.cpp/resolve/main/ggml-small.bin`（约 466MB）
   - 放置路径：`%LOCALAPPDATA%\smartbc\models\ggml-small.bin`
3. **录音测试**：切到「录音」页，点击圆形按钮说话，再点一次停止。历史页应出现转写文本。

## 隐私说明

- **本地优先**：录音音频、转写文本、记忆数据全部存储在你的电脑本地 SQLite 数据库（`%LOCALAPPDATA%\smartbc\smartbc.db`），不上传任何服务器。
- **云端仅文本**：只有转写后的**文字**会发送给 DeepSeek API 用于记忆抽取和回忆回答；音频文件永远不出本机。
- **数据控制**：「设置」页提供单条删除（历史页）、一键清空全部数据、导出全部数据为 JSON 文件。

## 常用操作

| 操作 | 位置 |
|---|---|
| 录音/停止 | 「录音」页大按钮 |
| 查看历史记录 | 「历史」页 |
| 回忆查询（问它） | 「回忆」页输入问题 |
| 查看记住的人脉/偏好 | 「人脉」页 |
| 承诺到期提醒 | 桌面通知（自动）；「承诺」页可标记完成 |
| 导出/清空/API Key | 「设置」页 |

## 每周统计

「设置」页可查看使用统计（录音次数、提问次数、承诺完成次数、最近 7 天活跃天数），用于收集反馈。

## 反馈收集

- 每周反馈问卷链接（由运营提供）
- 问题反馈：通过应用内「设置」页联系渠道，或直接回复邀请邮件

## 建议使用习惯

- 每天开启应用至少一次，随口说几条生活/工作事项
- 有承诺（"周三交方案"）时正常说话即可，应用会自动记住并到期提醒
- 想回忆过去说过的话，去「回忆」页提问
