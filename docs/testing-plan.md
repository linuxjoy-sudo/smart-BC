# SmartBC 功能测试计划（质量门槛）

> 目标：通过真实 API Key + 真实模型，验证软件功能完整性。修复"模型未加载"缺陷后的回归门槛。

## 测试环境

| 项 | 值 |
|---|---|
| 平台 | Windows 10/11（本机已装 `smartbc_0.1.0_x64-setup.exe` 新版） |
| 模型 | `%LOCALAPPDATA%\smartbc\models\ggml-small.bin`（465MB，已验证魔数 `lmgg`） |
| API | DeepSeek API Key（已配置） |

## 测试范围与门槛

每个功能模块必须**全部通过**才视为功能完整。任一项失败 = 质量门槛未达标，需修复后重测。

## 测试执行方式

**自动化优先**：后端命令层已由 37 个 Rust 单元测试覆盖（`cargo test`）。本计划聚焦**端到端 GUI 链路**（单元测试无法覆盖的部分），需人工在应用内操作，或通过 Tauri 命令注入测试。

## 自动化辅助测试（推荐先跑）

在 WSL 用真实 API Key 验证 LLM 链路（无需 GUI）：

```bash

DEEPSEEK_API_KEY=YOUR_KEY cargo test --test e2e_llm_test -- --ignored
```
